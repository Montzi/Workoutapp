# Dumbbelly images

## Where they go

Rename your `Dumbbelly` folder to `images`, then upload it to the repo root so the paths read:

```
images/ABS/  images/back/  images/Biceps/  images/Cardio/
images/Chest/  images/Legs/  images/shoulders/  images/Triceps/
```

If you upload it still named `Dumbbelly`, the app tries that second and still finds them.
Either works. `images` is tidier.

Folder names are case sensitive on GitHub Pages. Keep `back` and `shoulders` lower case
and `ABS` upper case, exactly as you have them.
